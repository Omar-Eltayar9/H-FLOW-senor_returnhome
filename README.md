# PX4 H-FLOW Return-to-Home System

## Description
This project implements a PX4 module that allows a drone to return home when drone be in close area and lose gps.

## Features
- Path-based return-to-home
- Waypoint logging
- Offboard control
- Automatic landing

## Technologies
- PX4 Autopilot
- C++
- Gazebo (SITL)

## My Contribution
- Modified open-source PX4 module
- Implemented return logic
- Integrated sensors (ToF, Optical Flow)
- Tested system in simulation
